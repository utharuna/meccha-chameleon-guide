GitHub Pagesで
HTMLを公開する方法

実際のスクリーンショット10枚で、最初から公開完了まで説明します。

無料画像付き初心者向け

目次

最初に確認 1. GitHubへログイン 2. リポジトリ作成 3. アップロード画面 4. ファイルを登録 5. 表示を待つ 6. 登録完了を確認 7. Pagesを開く 8. 公開元を設定 9. 公開処理を待つ 10. 公開完了 更新方法 困ったとき

この手順書の画像について

実際の操作画面を使用しています。ユーザー名は、説明用の架空名「sample-chameleon」に置き換えています。別の人が使う場合は、自分の名前に読み替えてください。

最初に確認すること

  • GitHubのアカウントがある
  • 公開用フォルダーにindex.htmlがある
  • CSS、JavaScript、画像がそろっている
  • 個人情報や公開前の画像が入っていない
  • Publicでは誰でも見られると理解している
リポジトリ作成→ファイル登録→Pages設定→URL共有

STEP 1

GitHubへログインする

ダッシュボード左側にある緑色のNewを押します。

STEP 2

新しいリポジトリを作る

項目設定例
Repository namemeccha-chameleon-guide
Description公開するページの説明
VisibilityPublic
Add READMEOn
.gitignore / License追加しない

設定後、画面下のCreate repositoryを押します。

Publicの注意：登録したファイルは誰でも見られます。秘密情報を入れないでください。

STEP 3

アップロード画面を開く

  1. Add fileを押す
  2. Upload filesを選ぶ

STEP 4

公開用ファイルを登録する

公開専用フォルダーの中身をアップロード枠へドラッグします。

入れるもの

  • index.html
  • style.css
  • script.js
  • assets
  • images

入れないもの

  • 元画像
  • バックアップ
  • 作業フォルダー
  • パスワード
  • 個人情報

Commit directly to the main branchを選び、Commit changesを押します。

重要：publicフォルダー自体ではなく、中身を入れます。index.htmlが一番上に見える状態が正解です。

STEP 5

ファイルが見えるまで待つ

登録直後にREADMEしか見えない場合は、30秒ほど待ってF5を押します。

STEP 6

アップロード完了を確認する

assets、images、index.html、script.js、style.cssが表示されたら成功です。

STEP 7

GitHub Pagesの設定を開く

  1. 上部のSettingsを押す
  2. 左側のPagesを押す

STEP 8

公開元を設定する

項目選ぶ内容
SourceDeploy from a branch
Branchmain
Folder/(root)

設定後、Saveを押します。

Start free for 30 daysやCustom domainは、通常の無料公開では不要です。

STEP 9

公開処理を待つ

保存後、GitHubがページを作ります。数分から10分ほど待ち、F5で更新します。画面を開いたままにする必要はありません。

STEP 10

公開完了を確認する

Your site is live at ...と表示されたら成功です。Visit siteで公開ページを開きます。

https://GitHubユーザー名.github.io/リポジトリ名/

Unpublish siteは公開を止めるボタンです。公開を続ける場合は押しません。

内容を更新する方法

  1. 公開用ファイルを修正する
  2. Add file → Upload filesを開く
  3. 変更ファイルを登録する
  4. Commit changesを押す
  5. 数分後に公開ページを確認する

公開URLは基本的に変わりません。

困ったとき

404と表示される

10分待ってF5を押します。index.htmlの位置と、Pagesのmain・/(root)設定を確認します。

画像だけ表示されない

imagesフォルダー、HTMLの画像名、大文字と小文字を確認します。

公開を止めたい

Settings → Pages → Unpublish siteを使います。

次回、Codexへ依頼する方法

$publish-static-html-github-pagesを使って、このHTMLをGitHub Pagesで公開してください。
GitHubの画面構成は、今後変更される場合があります。
